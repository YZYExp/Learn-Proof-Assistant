# 附录 B 术语与符号

| 术语 | 含义 | 容易误解之处 |
|---|---|---|
| 命题 proposition | 可以被证明的形式陈述 | 自然语言中的含糊条件不会自动补入 |
| 证明项 proof term | 具有相应命题类型的证据 | 策略脚本是生成它的一种办法 |
| 目标 goal | 当前需要构造证据的类型 | 不是程序运行时的待输出文本 |
| 上下文 context | 当前可用变量、类型和假设 | 假设可用不代表现实中已被满足 |
| 内核 kernel | 执行核心类型检查等规则的实现 | 整个编辑器和所有插件不都属于内核 |
| 展开 elaboration | 从方便书写的语法构造显式的内部表达 | 并非任意自然语言的自动理解 |
| 定义相等 definitional equality | 按系统计算规则被视作相同 | 与所有需要证明的数学等式不等同 |
| 命题相等 propositional equality | 由相等类型及其证据表达的等式 | 重写依赖等式的类型与方向 |
| 归纳 induction | 按生成结构建立普遍性质 | 不是从有限观察推测所有情形 |
| 递归 recursion | 按较小结构定义计算 | 对终止性有约束，不等于任意循环 |
| 策略 tactic | 构造证明或推进证明任务的程序 | 策略成功仍要看完整文件与公理依赖 |
| 引理 lemma | 用作后续推理的定理 | 与 theorem 的差异通常是组织意图 |
| 规格 specification | 对所需行为的精确陈述 | 规格可以写错或弱到没有实际意义 |
| 不变量 invariant | 在规定步骤中保持的性质 | 需证明起始成立及每步保持 |
| 公理 axiom | 在当前系统中被接受而未在此证明的陈述 | 不能因最终命令成功就忽略它 |
| 可信计算基 TCB | 保证成立所依赖的可信组件或假设集合 | 随声明的保证范围变化 |
| 提取 extraction | 从形式程序生成另一种语言程序的过程 | 生成器、目标工具链和部署仍有边界 |
| mathlib | Lean 的大型社区数学库 | 不等于 Lean 内核或 Lean 全部生态 |
| SSReflect | Rocq 生态中的证明语言与方法 | 不等于 Rocq 唯一可用的策略风格 |
| Coq / Rocq | 旧名称及现名称的资料连续性 | 老文档、文件扩展名和工具名不一定同步改名 |

| 符号 | 读法 |
|---|---|
| `P → Q` / `P -> Q` | 若 P 则 Q；构造从 P 证据到 Q 证据的转换 |
| `P ∧ Q` / `P /\ Q` | P 和 Q 都成立 |
| `P ∨ Q` / `P \/ Q` | 有 P 或 Q 的一侧证据，并说明是哪一侧 |
| `∀ x, P x` / `forall x, P x` | 对任意 x，P x 成立 |
| `∃ x, P x` / `exists x, P x` | 给出一个 x 及其满足 P 的证据 |
| `⊢ P` | 当前目标是证明 P |
